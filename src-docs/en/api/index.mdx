# API Overview

The `VrmCanvas` component has three kinds of API, and the package also exports helper functions:

| Page                       | Content                                                                        |
| -------------------------- | ------------------------------------------------------------------------------ |
| [Props](./props)           | Options for the model, animation, canvas, camera, and lights.                  |
| [Events](./events)         | Notifications for loading, animation, camera and light changes, and errors.    |
| [Instance API](./instance) | Methods available through a template ref.                                      |
| [Utilities](./utilities)   | Functions for validating and loading VRM / VRMA buffers without the component. |

```vue
<script setup lang="ts">
  import { ref } from 'vue';
  import { VrmCanvas, type VrmCanvasExposed } from 'vue-vrm';

  const modelData = ref<ArrayBuffer>();
  const canvas = ref<VrmCanvasExposed>();
</script>

<template>
  <VrmCanvas
    ref="canvas"
    :model-data="modelData"
    show-grid
    @model:loaded="() => canvas?.resetCamera()"
  />
</template>
```
